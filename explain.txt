##Student Chatroom System — Full Explanation

    This system allows students to join and chat in real-time with others in their class (based on standard and division). It uses a combination of frontend (HTML + JS), backend (Node.js + Express), a MySQL database, and Socket.IO for real-time messaging.

 1. How It Works — Step by Step
#Student Enters Details
    On the frontend, the student enters:
             - Their student_id
             - Their standard (e.g., 10)
             - Their division (e.g., A)

##Backend Finds Chatroom
#A POST request is sent to this endpoint:
--POST /api/:college_db/getChatroomId
      The backend uses standard and division to find the corresponding chatroom_id from the database.

##Socket Connects
Once the chatroom ID is found, the frontend:
             - Connects to the WebSocket using Socket.IO
             - Emits a join_room event with the chatroom_id and college_db
             - Receives chat history from the server for that room

##Real-Time Messaging
--When a message is typed and sent:
             - It’s sent to the server via the send_message socket event

##The server:
             - Saves the message in the database (messages table)
             - Broadcasts it to everyone in the same chatroom in real-time

2. Backend Breakdown
/controllers/studentController.js
Handles fetching the chatroom_id based on standard and division.

/controllers/messageController.js
saveMessage: Saves each message to the database.

getChatHistory: Fetches all previous messages for a chatroom.

/routes/chatRoutes.js
Defines the API routes for:

Getting chatroom_id

Saving and fetching messages (if needed)

/config/db.js
Manages database connections dynamically for each college_db.

🔌 Socket.IO in server.js
Listens for:

join_room: Adds the user to a chatroom and sends chat history.

send_message: Saves and broadcasts messages to the room.

## Frontend Flow (HTML + JS)
Collects student info via form.

Uses Axios to call the backend for chatroom ID.

Connects to Socket.IO.

Displays chat messages and updates them in real-time.
